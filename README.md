# rna-seq-transcriptome-bioinformatics-project
RNA-seq analysis of Escherichia coli for transcriptome profiling, gene expression quantification, and biological pathway interpretation.

## Overview

This project performs RNA-seq analysis of *E. coli* dataset including:

* Quality control (FastQC)
* Trimming (fastp)
* Alignment (Bowtie2)
* Gene counting (featureCounts)
* Expression analysis (TPM)

## Key Results

* 84% alignment rate
* 78% reads assigned to genes
* High expression of metabolic and transcription genes

## Tools Used

* FastQC
* fastp
* Bowtie2
* featureCounts
